# json.lua
**Небольшая и быстрая библиотека JSON для Lua.**
### Особенности
- Чистый Lua: работает с Lua 5.1, 5.2, 5.3, 5.4 и JIT
- быстрая: превосходит аналог от Rxi
- Компактна: менее 300 строк кода и около 7 килобайт
- Поддерживает разреженные массивы: например, `[true, null, false]` становится `{true, nil, false}`
- Красивая печать с помощью `json.prettify(table, tab [text: " "])` для удобочитаемого вывода с отступом
### Использование
**Библиотека предоставляет следующие функции:**
- `json.encode(value)` - *Кодирует значение Lua в строку JSON.*
- `json.encode({ 1, 2, 3, { x = 10 } })` - *Возвращает `[1,2,3,{"x":10}]`*
- `json.decode(value [string])` - *Преобразует строку JSON в значение Lua.*
```lua
json.decode('[1,2,3,{"x":10}]') -- return {1, 2, 3, { x = 10 }}

json.prettify({1, 2, { x = 10 }}, "  ")
-- Вывод: 
-- [1, 2, {
--   "x":10
-- }]
```
### Важно знать:
- Библиотека не будет автоматически преобразовывать или исправлять неподдерживаемые значения (например, `NaN`, `-inf`, `inf`).
- значения `null` будут преобразованы в `nil` во время декодирования и, таким образом, потеряются.
- В LuaJIT JSON библиотека Rxi будет быстрее
